# Type pairing

A showcase of the three families together, not a component: sans for every word meant for people, serif for the one human statement, mono only for figures, code and machine metadata.

- Do build every page on sans; add serif for announcements and long reads; let mono appear only where the brand book allows it.
- Don't set a serif and a sans paragraph side by side at the same size; the serif sits above, larger, or as a quote.
