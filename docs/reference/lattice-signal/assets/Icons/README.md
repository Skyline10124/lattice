# Icons

Fifty icons from IBM Carbon (`@carbon/icons`, Apache-2.0 — see `LICENSE.txt`), copied unchanged as their 32-unit master SVGs. They are single-ink and carry no colour of their own: shown as an `<img>` they are black. In pages use the `Icon` component, which draws the same artwork in the current text colour (`ink`, `ink-muted`, or `on-signal` in a primary button) at 16, 20, 24 or 32px.

Names follow Carbon: `play`, `pause`, `stop`, `restart`, `renew`, `terminal`, `code`, `document`, `folder`, `save`, `download`, `upload`, `copy`, `trash-can`, `edit`, `add`, `subtract`, `close`, `checkmark`, `search`, `settings`, `filter`, `time`, `calendar`, `chevron--up/down/left/right`, `arrow--left/right`, `launch`, `link`, `view`, `view--off`, `locked`, `unlocked`, `warning--alt`, `information--square`, `flash`, `chat`, `bot`, `data--base`, `cloud`, `branch`, `commit`, `tool-kit`, `list`, `grid`, `overflow-menu--horizontal`, `send`.
