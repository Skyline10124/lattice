### Task 4: P0-06 — Agent config integrity

- [ ] **Step 2: Add config integrity check**

  Add SHA-256 hash verification. Options:
  a) Compute hash at agent profile creation, store alongside config, verify on load
  b) Add signature field to agent TOML, verify with ed25519

  Given alpha timeline, choose option (a) — hash stored as comment or adjacent file:
  - Load profile
  - Read `.agent.toml.sha256` if exists
  - Verify `sha256(contents) == stored`
  - On mismatch: log warning or reject

  ```rust
  use sha2::{Sha256, Digest};

  fn verify_config_integrity(path: &Path, content: &str) -> Result<(), ConfigError> {
      let hash_path = path.with_extension("toml.sha256");
      if !hash_path.exists() {
          return Ok(());  // No hash file = no integrity check (graceful degradation)
      }
      let expected = std::fs::read_to_string(&hash_path)?.trim().to_string();
      let actual = format!("{:x}", Sha256::digest(content.as_bytes()));
      if actual != expected {
          return Err(ConfigError(format!(
              "Config integrity mismatch: {} (expected {}, got {})",
              path.display(), expected, actual
          )));
      }
      Ok(())
  }
  ```
