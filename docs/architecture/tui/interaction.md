# 浏览光标、评论与键盘

> 所属领域：[TUI 交互与视觉](README.md)

## 浏览光标

焦点可以离开输入区进入对话记录，用户借此定位要评论的内容并管理本地评论草稿。浏览光标就是终端光标，按显示格移动；宽字符占两格，光标只停在字符起点。

- **进入与离开：**在输入区首行按 ↑，光标移到对话记录最后一个视觉行；在对话记录最后一行按 ↓ 回到输入区。不在编辑时，Esc 在任何位置都只回到输入区。在对话记录中输入可打印字符或粘贴时被忽略，焦点不动，避免误输入；评论编辑器中照常输入。Dock 被 Warn 或 Error 占据时，本节所说“回到输入区”指焦点回到 Dock。
- **移动：**↑ ↓ 按视觉行移动，← → 按字符移动，Home 与 End 到行首行尾。光标可以停在标题线、空行、工具行、状态消息和启动横幅上。目标行在屏幕外时视图滚动一行跟上光标。
- **跟随：**焦点进入对话记录即暂停跟随，新内容流入时视图与光标不动，statusline 显示翻看提示；回到输入区或按 `Ctrl+End` 恢复跟随。
- **翻页：**PageUp、PageDown 与 Ctrl+End 只滚动视图。焦点在对话记录时，光标保持原列；滚出屏幕时移到屏幕上最近的一行。焦点在输入区时，翻页不移动光标。
- **Warn 与 Error：**浏览时有 Warn 或 Error 进入 Dock，焦点、光标与视图都不动，也不阻断对话记录中的按键：移动、翻页、Enter、Delete 与 Esc 照常执行，下一次按键不必是 Space。Space 释放它后焦点仍留在对话记录。只有焦点在 Dock 时才只处理 Space，见 [Warn 与 Error 模块](dock.md#warn-与-error-模块)。
- **锚定：**光标记为所在 Block 与其中的显示位置。生成中的文字追加、条目替换或插入更早的轮后按同一 Block 重新定位；Block 已不存在时，移到最近的 Block 开头。

Enter 与 Delete 的效果取决于光标位置；不在编辑时 Esc 一律回到输入区：

| 光标位置 | Enter | Delete |
| --- | --- | --- |
| 已关闭 Turn 的助手正文 | 进入 comment 模式，写新评论 | 无动作 |
| 本地评论草稿（屏内锚点下或底部兜底区） | 重新编辑 | 删除这条草稿 |
| 其他位置（含已发送评论卡片） | 无动作 | 无动作 |

## 评论

### 撰写与发送

1. 光标停在已关闭 Turn 的助手正文上，按 Enter。评论锚定到光标所在的 Markdown 块级元素：段落、标题、列表项、代码块中的一行或表格的一行。可评论的文字来自 Step 条目中的回复；生成中的文字和进行中 Turn 的文字不可评论。
2. 锚点元素下方展开评论编辑器，即草稿状态的评论卡片（见[显示与重载](#显示与重载)），标签行右端写 `草稿 · Enter 保存 · Esc 放弃 · #n`（若编辑期间原锚点已不在屏，则渲染在对话记录末尾兜底区，右端写 `草稿 · 原位置未显示 · Enter 保存 · Esc 放弃 · #n`）。编辑器按卡片内宽度折行，使用输入区相同的换行键。
3. Enter 保存草稿：原锚点在屏时回到锚点元素，原锚点不在屏时聚焦已保存在底部兜底区的草稿卡片自身。本地草稿仅在内存中保存显示顺序与动态局部编号 `#1`、`#2`……（新建未保存编辑器为 `#<草稿数 + 1>`），按内部块身份编辑与删除，不再维护全会话连续编号或已接受评论占用表。文字为空或只有空白时，Enter 删除这条草稿。
4. 新写的评论按 Esc 丢弃这条草稿；重新编辑已保存的草稿时按 Esc 放弃本次修改，恢复原文，草稿保留。不在编辑时光标停在屏内或底部兜底区的草稿上按 Delete 删除这条草稿（删除或放弃后若原锚点不在屏，光标重定位到邻近有效行或回到 Dock）；此时 Esc 只回到输入区，不删除草稿。
5. 用户在输入区按 Enter 时，全部本地草稿按顺序编码为自包含 `<lattice-comment>` 文本经 `Channel("tui/comment")` 发送；输入区非空时与 `Channel("tui")` 输入项按 `[tui/comment, tui]` 组成同一次 `TurnRequest` 原子提交（触发渠道恒为 `"tui"`），输入为空时仅发送 `[tui/comment]`。输入历史只记录输入区的非空文字，不含图片与评论元素；只含图片或评论的消息不写输入历史。
6. 带评论的提交确定未被后台接受（如 `PositionChanged`、`SettingsChanged` 或 `Busy`）时，不在对话记录中保留假 USER 块；提交所带的评论草稿完整恢复回本地草稿，**绝不**因原锚点暂不在屏而丢弃（仅含评论草稿且输入区为空时状态消息同样注明输入已保留）。提交结果未知时不提前恢复草稿，避免重复提交。

草稿只保存在本客户端内存中，退出时未发送的草稿丢失。

### 消息格式

评论以自包含格式写在独立的 `Channel("tui/comment")` 消息中，不携带任何跨节点的 `(turn, step, part, range)` 外键或全会话序号 `n`。每条评论由开始与结束标签包住，多条评论以空行（`\n\n`）分隔：

```text
<lattice-comment>
<quote>
• 终端宽度至少是高度的 3 倍
</quote>
这里的 3 倍是写死的吗？

能不能配置？
</lattice-comment>
```

| 部分 | 含义 |
| --- | --- |
| 开始标签 | `<lattice-comment>`，独占一行 |
| `<quote>` 段 | `<quote>` 与 `</quote>` 各独占一行，之间是被引用的助手原文，不加前缀 |
| 评论文字 | `</quote>` 之后、结束标签之前的批注正文，保留换行与空行 |
| 结束标签 | `</lattice-comment>`，独占一行 |

原文或评论文字中某行去掉可选行尾 `\r` 后恰为若干 `\` 加 `</quote>` 或 `</lattice-comment>` 时，写出时在行首多加一个 `\` 并保留原行尾 `\r`，解析时去掉一个 `\` 并保留原行尾 `\r`；其余文字原样写出，确保含 `\r\n` 的内容往返无损。

### 显示与重载

- 仅当 `Input` 条目的渠道为 `tui/comment` 且仅含单个 `Text` 片段，同时整段文本严格符合上述自包含格式（每条批注非空且规范往返一致）时，session 将其解析为内联只读评论卡片列表；其他渠道或不符合规范/含图片的 `tui/comment` 条目按普通用户消息渲染，其中的原始标签按原文显示。
- **已发送评论**在所属 `USER · tui/comment` 标题线下方原地渲染为只读评论卡片，卡片之间空一行，横向铺满对话记录宽度（`indent = 0`），左右各留两列内边距。卡片自上而下为：上边距一行；标签行，左侧是 ` COMMENT ` 标签（两端各留一格，标签底色、Assistant 前景、加粗），右端以 DimMeta 写块内局部序号 `#1`、`#2`……；空行一行；以 `DimMeta` 与 `▎ ` 前缀折行显示的引文预览；空行一行；以 `Assistant` 折行显示的批注正文；下边距一行。不再在 `USER` 消息中渲染 `[COMMENT n]` 跳转标记，也不再跨块挂回原 `Step` 或出现 `原文不匹配`。
- **本地评论草稿**支持屏内与屏外双挂载：
  - 当原锚点元素在当前对话记录中且原文仍与 `quote` 一致时，该元素铺评论锚点底色（从元素正文起点到文字结束处，不含列表符号、引用线与代码块/表格框线），草稿卡片紧跟在锚点元素下方并从锚点正文起点向右铺底色，右端写 `草稿 · #k`（编辑中附 `Enter 保存 · Esc 放弃`）。
  - 当原锚点当前不在屏幕上时（例如重连回放未到齐、分页未装入更早轮次、外部 `ContextOp` 修改或外部 `rewind` 后），草稿（含正在编辑的编辑器）自动挂载在**对话记录末尾、`SubmissionWait` 之前**（包括前面有 0 行内容时），`indent = 0`，右端写 `草稿 · 原位置未显示 · #k`，卡片内上方以 `DimMeta` 与 `▎ ` 前缀展示引文预览，空一行后展示草稿正文或输入框，照常支持 `Enter` 编辑与 `Delete` 删除，绝不悬空不可见或自动丢弃。

## 键盘

| 输入 | 条件 | 行为 |
| --- | --- | --- |
| Enter | 输入区，空闲且无在途 `configure` | 提交输入与评论草稿，两者皆空时不提交 |
| Enter | 输入区，Turn 运行中或有在途 `configure` | 本地指令照常执行；普通提交不发出请求，显示 Warn 并保留输入与评论草稿 |
| Enter | 对话记录 | 按[浏览光标](#浏览光标)中的位置表执行 |
| Enter | 编辑评论 | 保存草稿 |
| Alt+Enter | 输入区或评论编辑器 | 换行 |
| Shift+Enter | 输入区或评论编辑器，且 kitty keyboard protocol 可用 | 换行 |
| 可打印字符、bracketed paste | 输入区或评论编辑器 | 可打印字符直接插入；输入区中的粘贴先按下方规则识别本机图片路径，其余粘贴与评论编辑器中的粘贴原样插入、保留换行，不提交 |
| 可打印字符、bracketed paste | 对话记录 | 忽略，焦点不动 |
| Backspace、Delete | 输入区或评论编辑器 | 删除 |
| Delete | 对话记录 | 按[浏览光标](#浏览光标)中的位置表执行 |
| ←、→、Home、End | 输入区、评论编辑器或对话记录 | 行内光标移动 |
| ↑ | 输入区，不在首行 | 光标上移 |
| ↑ | 输入区，在首行 | 进入对话记录 |
| ↓ | 输入区，不在末行 | 光标下移 |
| ↑、↓ | 对话记录 | 按视觉行移动；在最后一行按 ↓ 回到输入区 |
| Ctrl+↑、Ctrl+↓ | 输入区 | 上一条、下一条输入历史 |
| Ctrl+V | 输入区 | 见下方「剪贴板」 |
| PageUp、PageDown | 全局 | 滚动视图；对话记录中的光标限制在屏幕内 |
| Ctrl+End | 全局 | 回到底部并恢复跟随 |
| Esc | 输入区 | 清空输入 |
| 可打印字符、bracketed paste、Backspace | Dock 栈顶是选择面板 | 编辑过滤文字 |
| ↑、↓ | Dock 栈顶是选择面板 | 移动光标 |
| Enter | Dock 栈顶是选择面板 | 选定并关闭面板 |
| Esc | Dock 栈顶是面板 | 关闭面板；选择面板不改变选择 |
| Esc | 对话记录，不在编辑 | 回到输入区 |
| Esc | 编辑评论草稿 | 放弃草稿或放弃本次修改 |
| 无修饰 Space | WARN/ERROR 显示时，输入区或浏览光标 | 释放状态，焦点不变，不进入缓冲；评论编辑器中照常插入空格 |
| Ctrl+C | 第一次 | Turn 运行中请求协作取消；空闲时清空输入；两秒内再次按下则退出 |
| Ctrl+D | 输入区，缓冲为空 | 退出 |

启动时探测一次 keyboard enhancement 支持，换行键提示与探测结果一致。

- **粘贴识别。** 粘贴目标是输入区时，去掉首尾空白后的单行内容先尝试解析路径：`file:///` 与 `file://localhost/` URI 对去掉 `localhost` 后的 `/…` 路径做 `%HH` 解码得到 Unix 路径字节（其他 `file://` 形式或解码失败按文字处理），成对单引号包裹的取引号内原文，未加单引号的把 `\X` 还原为 `X`；相对路径相对于进程当前目录。目标路径指向本机常规文件且魔数识别为 PNG、JPEG、WebP 或 GIF（见[图片引用](../../reference/glossary.md)）时，单张长度合规且加入后不超过单轮图片张数与总字节上限（见[输入与传输限制](../session/concurrency.md#输入与传输限制)）即插入图片原子，单张超限或加入后超过单轮张数、总量则显示一条 Error 状态消息且不插入内容；其余情况（含多行内容、路径不存在、不是常规文件、读取失败或魔数不是受支持图片，以及评论编辑器与选择面板过滤框中的粘贴）一律按普通文字插入。
- **剪贴板。** 按下 `Ctrl+V` 时读取剪贴板。每条子进程命令限时 1 秒，最多读取 `MAX_IMAGE_BYTES + 1` 字节；读到上限即终止子进程，显示一条 Error 状态消息，不插入内容。
  - **读取工具。** `WAYLAND_DISPLAY` 非空时，用 `wl-paste --list-types` 列类型，用 `wl-paste --no-newline --type <mime>` 读取；否则 `DISPLAY` 非空时，用 `xclip -selection clipboard -t TARGETS -o` 列类型，用 `xclip -selection clipboard -t <mime> -o` 读取。
  - **图片。** 列出的类型含图片时，按 `image/png`、`image/webp`、`image/jpeg`、`image/gif` 的优先级取第一个读取。单张长度合规、文件头是受支持的图片格式，且加入后不超过单轮图片张数与总字节上限时，写入私有暂存目录，在光标处插入图片原子；长度不合规、文件头不是受支持的格式、加入后超过单轮上限或暂存失败时，显示一条 Error 状态消息，不插入内容。
  - **文字。** 没有图片类型时读取纯文本：Wayland 依次找 `text/plain;charset=utf-8`、`text/plain`，X11 依次找 `UTF8_STRING`、`text/plain;charset=utf-8`。类型名不区分大小写。读到的文字须是有效的 UTF-8，按粘贴文字插入，同样先做上条的路径识别。
  - **Warn。** 没有图形会话环境变量、未安装 `wl-paste` 或 `xclip`（提示安装对应工具，或直接粘贴本地图片路径），以及子进程超时、非零退出、剪贴板中没有图片或文字、文字不是有效的 UTF-8 时，显示一条 Warn 状态消息。
  - **私有暂存目录。** 本进程首次暂存剪贴板图片时，在 `/tmp` 下独占创建模式为 `0700` 的目录，不跟随符号链接，并核验属主为当前有效 UID。图片文件以 SHA-256 的小写十六进制命名，模式为 `0600`。TUI 正常退出时删除整个目录。
- **输入历史与被拒恢复。** 输入历史尽力保存到 `<session_dir>/repl_history.txt`，沿用纯文本行格式，只记录非空文字，不记录图片；图片只在输入区为空时随未被接受的提交整条放回输入区。

raw 模式下 Ctrl+C 作为 KeyEvent 处理，不另起系统信号 watcher。应用循环按上述键位发出动作，后台取消与前端退出的交接见[取消、退出与恢复提示](README.md#取消退出与恢复提示)。
