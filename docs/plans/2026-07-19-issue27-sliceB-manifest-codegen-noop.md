## B.2 WIT world（generated，`tools/noop/generated/tool-host.wit`）

```wit
// @generated by `cargo xtask tool-codegen` from tools/noop/manifest.toml.
package lattice:tool-host@0.1.0;

interface host-control {
    /// Cooperative cancellation probe (host also enforces epoch deadline).
    cancelled: func() -> bool;
    /// Structured progress event, mirrored to the CEP event stream.
    emit-event: func(payload: string);
}

interface tool-api {
    record tool-output {
        /// Trust-free 3-segment CellRef; host derives trust from descriptor.
        result-cell: string;
        value-json: string;
    }
    run: func(params-json: string) -> result<tool-output, string>;
}

world tool {
    import host-control;
    export tool-api;
}
```

约束：#27 no-op **不导入任何 domain operation channel**；只导入无领域权限的 `host-control`，
避免在 #28 admission 落地前形成“声明即授权”的旁路。`tool-api` export 的 result sink 是 host-owned
Session result adapter：它只接收/验证 ToolOutput，不向 guest 暴露 session operation，因而可满足
descriptor 派生的 Session channel。`result-cell` 由 host 校验并记 `(Alloc,None,session/in)` evidence。
world 不出现任何 `wasi:*`；guest target 为 `wasm32-unknown-unknown`，import 白名单恰等于 host-control。

## B.3 `xtask tool-codegen`（确定性生成器）

```rust
// xtask/src/tool_codegen.rs（骨架）
pub fn run(check: bool) -> anyhow::Result<()> {
    for manifest_path in discover_tool_manifests()? {          // tools/*/manifest.toml
        let m = parse_manifest(&manifest_path)?;               // TOML + deny_unknown_fields
        // Manifest cell string is a canonical 3-segment CellRef; parse it
        // explicitly to `Cell`. Descriptor JSON serializes the owning object.
        let descriptor = lower_manifest(m, parse_cell_ref)?;
        descriptor.validate()?;
        let out = Outputs {
            wit: render_wit(&m),                                // B.2
            descriptor_json: render_canonical_descriptor_json(&m), // owning ToolDescriptor JSON
            llm_projection: render_llm_tool_definition(&m),     // name/description/params_schema
            registration_rs: render_inventory_registration(&m), // name + embedded bytes only
            identity_json: render_expected_identity_candidate(&m), // trusted host build input
        };
        // Determinism: stable field order, no timestamps, \n endings, one
        // trailing newline. `check` mode diffs instead of writing (CI gate).
        write_or_check(&manifest_path, out, check)?;
    }
    Ok(())
}
```

generated Tool registration（不能自批；只提交 name + bytes）：

```rust
// @generated — do not edit.
pub static NOOP_ECHO: lancet_runtime::EmbeddedTool = lancet_runtime::EmbeddedTool {
    name: "noop.echo",
    descriptor_json: include_bytes!("descriptor.json"),
    component_bytes: include_bytes!("noop_echo.component.wasm"),
};
inventory::submit!(&NOOP_ECHO);
```

另生成未链接的 `expected-identity.json` candidate（descriptor/artifact digest、ABI、imports）。
只有 trusted host composition step 选择它后，才写进 `lancet-runtime/src/generated/host_composition.rs`；
Tool crate 无法把 candidate 自行提交为 approval。

`xtask ci` 追加两门：`tool-codegen --check`（重跑 diff）+ `tool-build --verify`
（rebuild-and-compare，**warn-only** 起步，决议 1）。

## B.4 `lattice-tool-prelude` + no-op guest

```rust
// crates/lattice-tool-prelude/src/lib.rs（对 guest 的唯一 API 面）
#![no_std]
extern crate alloc;
pub use wit_bindgen; // pinned re-export; guests never depend on it directly

/// Implement your tool as a plain function; the macro wires the Component
/// export glue. Host internals are not reachable from this crate.
#[macro_export]
macro_rules! export_tool {
    ($ty:ty) => { /* generated bindings glue: world `tool` export -> $ty::run */ };
}
```

```rust
// tools/noop/src/lib.rs — the tracer guest
#![no_std]
extern crate alloc;
use alloc::{format, string::String};
use lattice_tool_prelude::export_tool;
use crate::bindings::lattice::tool_host::host_control;

struct NoopEcho;

impl Guest for NoopEcho {
    fn run(params_json: String) -> Result<ToolOutput, String> {
        if host_control::cancelled() {
            return Err(String::from("cancelled"));
        }
        // ToolHost control is exercised, but no workspace/network/session
        // domain operation is available before #28 capability admission.
        host_control::emit_event("{\"phase\":\"probed\"}");
        let message = extract_message(&params_json)?;
        Ok(ToolOutput {
            // Guest reports a trust-free CellRef. Host resolves `session`
            // in the descriptor and alone appends `:in` to the audit key.
            result_cell: String::from("alloc:none:session"),
            value_json: format!("{{\"echoed\":{}}}", json_string(&message)),
        })
    }
}
export_tool!(NoopEcho);
```

> `#![no_std]` + `wasm32-unknown-unknown`：链接产物 import 集恰好等于 WIT world；
> 任何越界 import（包括意外引入 std 的 `wasi:*`）在切片 C 的 gate 直接可见。

## B.5 测试

| 用例 | 断言 |
| --- | --- |
| codegen determinism | `tool-codegen` 双跑 byte-identical；golden 文件比对 |
| manifest drift | 手改 generated descriptor 一个字段 → `--check` 失败 |
| manifest 校验 | 未知字段 / cell 引未声明 scope / 重复名 → 解析期报错 |
| WIT validity/closure | `wasm-tools component wit` + `wasm-tools validate` 成功；imports 恰为 host-control 且无 `wasi:` |
| guest 构建 | `cargo build -p noop-echo --target wasm32-unknown-unknown` + component encoding 成功 |
| artifact hash | `tool-build` 写回的 sha256 与产物一致 |
