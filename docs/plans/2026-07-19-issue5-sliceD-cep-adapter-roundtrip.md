## D.1 `lancet-dispatch`：只补 typed named client，不开放 registrar

**不新增 `register_raw(name, closure)`。** 那会成为任意 linked code 可调用的 runtime-registration
seam，违背 build-closed。5 个 native method 继续留在现有 `MethodRegistry`；Component 方法由
`lancet-runtime::ClosedCatalog` 私有 map 在 native lifecycle 内直接分流（D.3）。

`CepClient` 可公开 name-dynamic、type-static 的 transport helper；现有 `call<M>` 委托它：

```rust
// crates/lancet-dispatch/src/transport.rs
pub async fn call_named<P, R>(&self, method: &str, params: P) -> Result<R, CepError>
where
    P: serde::Serialize,
    R: serde::de::DeserializeOwned,
{
    let raw_params = serde_json::to_value(params).map_err(|e| {
        CepError::invalid_params(format!("failed to serialize {method} params: {e}"))
    })?;
    let raw = self.call_raw(method.to_owned(), raw_params).await?;
    serde_json::from_value(raw).map_err(|e| {
        CepError::internal_error(format!("failed to deserialize {method} result: {e}"))
    })
}

pub async fn call<M>(&self, params: M::Params) -> Result<M::Result, CepError>
where M: CatalogMethod, /* existing bounds */ {
    self.call_named(M::NAME, params).await
}
```

该 helper 不承载 schema；Component params/result 仍由 generated descriptor validators 强制。
#12 吸收 transport 后将 helper 搬入 `lancet-runtime`。测试：`call<M>` 回归、`call_named`
serialize/deserialize failure、取消/事件顺序不变。

## D.2 host-owned composition：一次构造、无自批准

approval 不是 inventory item。trusted host build 私有 pin 完整 identity，而不只 pin name：

```rust
// crates/lancet-runtime/src/generated/host_composition.rs
// @generated by trusted host composition; Tool crates cannot submit to it.
pub(crate) const EXPECTED_COMPONENTS: &[ExpectedToolIdentity] = &[];
// #5 production empty; entries pin name + descriptor/artifact digest + ABI + imports.
```

Tool crate 只可提交 name + embedded bytes；`from_embedded()` 将它与 private expected identities
精确比较。冒充已批准 name 但 digest/import/ABI 不同仍 fail closed。#7 迁首个 production Component
时，trusted host build 才更新该表。

`LancetRuntime::build` **compose 一次**，同一个 `Arc<ComponentRuntime>` 同时供 projection 与 server：

```rust
let components = Arc::new(ComponentRuntime::from_embedded()?);
let mut available = project_tool_definitions(catalog()); // 5 native, temporary
available.extend(components.llm_definitions());           // generated descriptors
let exposure = resolve_enabled_tools(&enabled_tools, &available)
    .map_err(map_tool_exposure_err)?;

let (client, lifecycle) = LancetServer::spawn_composed(
    server_config,
    DEFAULT_CHANNEL_CAPACITY,
    Arc::clone(&components),
 )?;
```

`spawn_composed` 为 `pub(crate)`；public `LancetServer::spawn` 自己 compose 一次后委托它。
不存在注入 path/bytes/handler 的 public config，也不存在第二个 engine/catalog authority。

## D.5 `lattice-api::CepExecutorAdapter` 删除硬编码 catalog/match gate

当前 `catalog_names` 来自 central catalog、`dispatch_typed` 硬编码五臂
（`turn/cep.rs:70-152`）。改成 runtime definitions 驱动 available set，所有方法走 server raw dispatch；
native registry 自己仍做 typed params/result 校验：

```rust
pub struct CepExecutorAdapter {
    client: CepClient,
    available_names: HashSet<String>,
    enabled_names: HashSet<String>,
}

impl CepExecutorAdapter {
    pub fn new(
        client: CepClient,
        definitions: &[lancet_cep::ToolDefinition],
        enabled_names: impl IntoIterator<Item = impl Into<String>>,
    ) -> Self {
        Self {
            client,
            available_names: definitions.iter().map(|d| d.name.clone()).collect(),
            enabled_names: enabled_names.into_iter().map(Into::into).collect(),
        }
    }
}

#[async_trait]
impl ToolCallExecutor for CepExecutorAdapter {
    async fn execute(&self, call: &ToolCall) -> Result<String, ToolExecutionError> {
        let name = &call.function.name;
        if !self.available_names.contains(name) || !self.enabled_names.contains(name) {
            return Err(Self::map_cep_error(method_not_found(name)));
        }
        let params: Value = serde_json::from_str(&call.function.arguments)
            .map_err(|e| Self::map_cep_error(parse_error(format!(
                "invalid tool arguments JSON: {e}"
            ))))?;
        let value = self.client.call_raw(name.clone(), params)
            .await
            .map_err(Self::map_cep_error)?;
        serde_json::to_string(&value)
            .map_err(|e| ToolExecutionError::simple(format!("serialize tool result: {e}")))
    }
}
```

删除五个 method type imports、`dispatch_typed`/`call_typed`/`schema_mismatch_for_method`；
保留 adapter error payload 映射。这样 inventory Tool 不再被 central catalog membership 阻断。

## D.6 end-to-end test（Value transport + schema validation + event + audit）

不生成任意 JSON Schema → Rust struct（超出 #5，也会制造第二 schema 表示）。测试从 composed
descriptor 取 method name，params/result 用 `serde_json::Value`；runtime validator 保证结构：

```rust
#[tokio::test]
async fn embedded_noop_round_trips_through_cep_and_audit() {

    // Zero-argument, fixed generated fixture: caller cannot inject bytes,
    // registrations, handlers, paths, or an approval set.
    let components = ComponentRuntime::noop_fixture()
        .expect("closed no-op test composition");
    let method = components.descriptors().next().unwrap().name.clone();
    let (client, audit, lifecycle) = spawn_native_for_test(components).await;

    let value: serde_json::Value = client
        .call_named(&method, serde_json::json!({ "message": "ping" }))
        .await
        .expect("component round trip");
    assert_eq!(value, serde_json::json!({ "echoed": "ping" }));

    let rows = audit.query(/* method=noop.echo */).expect("audit");
    assert_eq!(rows.len(), 1);
    assert_eq!(rows[0].outcome, "success");
    assert!(rows[0].metadata.as_deref().unwrap().contains("alloc:none:session:in"));

    lifecycle.shutdown().await;
}
```

放在 `lancet-native` unit tests（可调用 private `spawn_native_for_test`）；runtime 只经非默认
`test-utils` 暴露零参数 fixed `noop_fixture()`，不暴露 generic compose。另测：

- `CepExecutorAdapter` 用 no-op descriptor definition 执行成功（LLM path 可达）；
- `CallControl::cancel` → `CallCancelled`，audit outcome = cancelled；
- event receiver 收到 started/probed/finished 且 call id 一致；
- trap/timeout/exhaustion 后再调用成功（server 未崩）。
