# 项目 Skills

本目录保存项目 skill 入口及其依赖的源资料。Pi 与 Delta 共用仓库内的同一份工作流，不依赖用户主目录中的 skill 安装。

## 目录职责

- `skills/<name>/SKILL.md`：供宿主发现的项目入口，维护触发条件、项目适配和必读资料指针。
- `skill-sources/<name>/`：对应工作流的源文件、附件、模板、脚本及原有显示元数据。
- [Pi 说明](README.pi.md)与 [Delta 说明](README.delta.md)：宿主的加载、工具和执行方式。

源目录中的 `SKILL.md` 与 `agents/openai.yaml` 作为源资料保存，不另行注册为宿主 skill 或角色。项目 skill 的发现入口仍是 `skills/`。

## 来源与维护

源资料从用户提供的 `~/.agents/skill/` 中按项目已有 skill 导入，保留原文和目录结构，便于核对方法、示例及附件是否完整承接。该路径只记录导入来源，不参与运行时加载。

源资料与项目适配均在本仓库内维护；更新时检查两者是否仍然匹配，不自动同步或改写用户主目录中的副本。导入的外部方法原文保留原语言，项目说明和适配使用中文。

项目入口是使用这些方法的唯一有效入口。先遵循根及目标路径的 `AGENTS.md` 和入口中的项目适配，再使用源方法；源文件的搬入不改变项目合同、任务授权或批准关系。

## 读取与检查

从项目入口的相对链接直接读取源工作流，不再次调用同名 skill。附件链接相对于源文件所在目录解析；源方法提到的 `docs/` 等项目路径相对于仓库根目录解析。跨 skill 调用仍使用项目入口。

源文件或附件缺失时报告仓库内的缺失路径，不回退到全局副本，也不自动安装。修改后检查：

- 每个项目入口都能找到对应源工作流，条件分支所需附件、模板和脚本齐全。
- 相对链接有效，读取过程不需要用户主目录中的源文件。
- 元信息与项目适配保留，源方法中的通用示例没有覆盖项目约束。
- 在实际宿主中核对 skill 的加载路径；文件与链接检查不等于已验证宿主发现行为。
