<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI profile source -> runtime | Local `agent.toml` and prompt files are loaded into runtime execution configuration. |
| CLI credentials -> runtime | Provider credentials are passed to runtime builder and must not enter snapshots/manifests. |
| runtime events -> CLI renderer | Streamed model/tool data crosses into terminal output. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | profile source fingerprint | mitigate | Compute source fingerprint from loaded profile bytes and pass it to runtime so session drift is detected and locked snapshots are respected. |
| T-02-04 | Information disclosure | CLI profile helper | mitigate | Pass credentials only through `Runtime::builder().credentials`; do not include credential maps or env values in `AgentSessionRequest` or source audit. |
| T-02-05 | Repudiation | CLI completion handling | mitigate | Await `SubmittedTurn.completion` and preserve Error/Cancelled status gating instead of ignoring terminal status. |
| T-02-06 | Elevation of privilege / confusion | old pipeline/plugin runtime builder calls | mitigate | Remove compile-critical calls to runtime extension builder APIs; leave final command UX cleanup to Phase 3. |
</threat_model>
