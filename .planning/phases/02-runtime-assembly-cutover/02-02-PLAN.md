<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| profile spec -> runtime assembly | Pure profile data controls prompt, model id, tool exposure, and security intent, while runtime invocation supplies cwd/project_root/effective security. |
| runtime assembly -> tool executor | Model-visible tool definitions become executable tool calls crossing sandbox/policy boundaries. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Elevation of privilege | `assemble_generic_agent` tool executor | mitigate | Build `DefaultToolExecutor` with `RuntimeSecurity.sandbox.clone()` and `with_authorized_tools(capabilities.tool_names.clone())`; test denied unenabled tool or blocked operation. |
| T-02-04 | Information disclosure | profile snapshot serde round trip | mitigate | Serialize only `GenericAgentSpec` fields from profile data; do not include credentials or env-derived secrets in runtime assembly input. |
| T-02-06 | Elevation of privilege / confusion | accidental orchestrator assembly reuse | mitigate | Source guard in `assembly.rs` rejects `lattice_orchestrator::assembly`, `AgentTurnSpec`, and `RuntimeAgentSpec`. |
</threat_model>
