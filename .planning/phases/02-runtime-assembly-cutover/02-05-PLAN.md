<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| TUI state -> runtime session | Interactive UI state selects a runtime profile/session and submits prompt input. |
| runtime event stream -> TUI | Model/tool/sandbox events become terminal UI updates. |
| plugin UI leftovers -> runtime | Old plugin UI state must not mutate runtime execution after plugin overlay API removal. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03 | Elevation of privilege | TUI plugin overlay path | mitigate | Remove `RuntimePluginOverlay` dependency and do not pass plugin tool overlays into runtime from TUI. |
| T-02-05 | Repudiation | TUI completion handling | mitigate | Await `SubmittedTurn.completion` and propagate Completed/Error/Cancelled status into existing terminal handling. |
| T-02-06 | Elevation of privilege / confusion | TUI live handle state | mitigate | Frontend guard rejects `AgentHandleId`, handle creation, and completion cache calls in TUI runtime adapter files. |
</threat_model>
