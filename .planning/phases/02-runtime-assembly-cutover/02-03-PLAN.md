<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| prepared session -> turn submission | A prepared profile/session context becomes a model-visible turn. |
| runtime stream -> session commit | Model/tool execution output becomes durable conversation and manifest state. |
| cancellation/error -> audit log | Non-success outcomes cross from transient execution into durable status records. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-01 | Tampering | locked snapshot deserialization | mitigate | Use `OpenedTurn.profile_snapshot.canonical_spec` for assembly, not the changed caller spec, when session returns a locked snapshot; expose `profile_drift_warning` and manifest `profile_drift` metadata with the locked snapshot hash. |
| T-02-02 | Tampering | runtime commit | mitigate | Pass `OpenedTurn.base_commit_id` into `CommitTurnRequest`; rely on session rejection before mutation. |
| T-02-05 | Repudiation | `TurnCompletion.status` | mitigate | Map Completed/Error/Cancelled to `TurnOutcomeStatus` and manifest metadata through `commit_turn`. |
| T-02-06 | Elevation of privilege / confusion | event identity | mitigate | Remove `AgentHandleId` from generic runtime events/completions and use `session_id + turn_id` instead. |
</threat_model>
