## Decision Coverage

- D-02: Discovery preserves `.lattice/agents/<name>/agent.toml` and `~/.lattice/agents/<name>/agent.toml`; it does not introduce `.lattice/profiles/` or `profile.toml`.
- D-03: Agent packages remain folders containing `agent.toml` plus optional neighboring files such as `prompt.md`.
- D-05: Explicit paths win; named lookup checks project-local before user-global and project-local overrides global.
- D-06: Missing agent selection resolves `default` through project-local then user-global default agent package paths.
- D-07: Missing default returns a contract for interactive creation and template text; `lattice-profile` does not write files unexpectedly.
- D-08: Generated default template includes prompt text and comments telling users to edit role, prompt, tools, and security settings.
- D-17: Discovery, default template, and pure lowering are owned by `lattice-profile`.
- D-18: Discovery/lowering avoid runtime, orchestrator, agent, session, plugin, CLI, and TUI dependencies.
- D-19: Lowered specs defer model/provider/tool/sandbox semantic validation to runtime and tools.
- D-20: `lattice-agent` remains outside profile loading and lowering.
- D-26: Coding-capable behavior is represented as a normal profile prompt plus selected tools.
- D-29: Lowering carries `[tools].bundles` and `[tools].enabled` forward as data.
- D-32: Bundle/tool name existence is not validated by `lattice-profile`.
</decision_coverage>

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| caller -> discovery API | CLI/runtime caller supplies project and global directories that determine which user file is loaded. |
| profile contract -> runtime assembly | Pure spec crosses into later runtime phases where model/tool/sandbox semantics are validated. |
| missing default -> filesystem creation | A missing default can tempt code to write files without user consent. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-05 | S/T | `discovery.rs` lookup order | mitigate | Explicit path wins; named/default lookup uses project-local before global and tests override semantics. |
| T-01-06 | T | `discovery.rs` missing default behavior | mitigate | Return `MissingDefault` with template/create path; do not write files from `lattice-profile`. |
| T-01-07 | E | `lowering.rs` pure conversion | mitigate | Source guard forbids runtime/agent/session/plugin/CLI imports and preset symbols; tests prove no live assembly fields. |
| T-01-08 | E | `defaults.rs` generated template | mitigate | Template emits `[tools]` bundles/enabled only and excludes legacy presets/capabilities/approval grants. |
</threat_model>
