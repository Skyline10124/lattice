    - Build agent_request via build_agent_request(request, &prepared.session_id, prepared.transcript, prepared.model.clone(), prepared.system_prompt.clone(), Some(prepared.provider.clone()).filter(|p| p != "unknown")) (per D-15)
    - Create agent channel: let (agent_tx, mut agent_rx) = mpsc::channel(TURN_EVENT_CHANNEL_CAPACITY)
    - Pin agent future: let mut agent_fut = Box::pin(agent_loop.run_turn_live(agent_request, agent_tx))
    - MANDATORY select! concurrent drain loop (per D-20):
      ```
      let agent_result = loop {
          tokio::select! {
              maybe_event = agent_rx.recv() => {
                  if let Some(event) = maybe_event {
                      emit_turn_event(&turn_tx, map_agent_event(event)).await;
                  }
              }
              result = &mut agent_fut => {
                  break result;
              }
          }
      };
      ```
    - Post-loop drain: while let Some(event) = agent_rx.recv().await { emit_turn_event(&turn_tx, map_agent_event(event)).await; }
    - Terminal event: if let Some(terminal) = derive_terminal_event(&agent_result) { emit_turn_event(&turn_tx, terminal).await; }
    - Emit TurnCommitting
    - Build commit context: TurnCommitContext { session_id: prepared.session_id.clone(), parent_ids: prepared.parent_ids, model: prepared.model, provider: prepared.provider, profile_snapshot_id: prepared.profile_snapshot_id }
    - Build commit input: build_commit_input(&request.input, &ctx, &agent_result)
    - Call session.commit_turn(commit_input): match result { Ok(commit) => emit TurnCommitted { session_id: prepared.session_id, commit_id: commit.commit_id, status: map_status(&agent_result.status) }, Err(e) => emit CommitFailed { reason: e.to_string() } } (per D-13)
    - Function ends, turn_tx drops, stream closes.

    Public function `pub(super) async fn stream_turn_live(session: SessionApi, agent_loop: Arc&lt;AgentLoop&gt;, request: RunTurnRequest) -> Result&lt;TurnEventStream&gt;`:

    - tokio::spawn(async move { run_live_turn_task(session, agent_loop, prepared, request, tx).await; })
    - Return Ok(Box::pin(ReceiverStream::new(rx)))
