  <action>
Replace the outer `apply_optional_timeout` wrapper with a cooperative deadline threaded into `run_turn_inner`. The approach per D-13:

1. Remove `apply_optional_timeout` function entirely.

2. In `run_turn` and `run_turn_live`, compute `deadline: Option<tokio::time::Instant>` from `request.timeout.map(|d| tokio::time::Instant::now() + d)` BEFORE calling `run_turn_inner`. Pass `deadline` as a new parameter to `run_turn_inner`.

3. Add a new `StreamOutcome::TimedOut` variant to the `StreamOutcome` enum. This is distinct from `StreamOutcome::Error` — timeout is NOT a provider error. The timeout path must produce `terminal_reason: Some("timeout".to_string())`, not `"LLM error: timeout"`. Handle `StreamOutcome::TimedOut` in `run_turn_inner` alongside Error: call `flush_partial_assistant_message`, return `AgentTurnResult` with `status: Error`, `terminal_reason: Some("timeout".to_string())`, preserving `all_messages`, `all_events`, `accumulated_usage`, `tool_summaries`.

4. In `run_turn_inner`, wrap the `self.config.llm.stream_chat(chat_request).await` call in a `tokio::select!` against the deadline. Check `now >= deadline` first to avoid select race when deadline is already past:
   ```
   let stream = match deadline {
       Some(dl) if tokio::time::Instant::now() >= dl => {
           // deadline already passed
           return /* Error result with accumulated state, terminal_reason: "timeout" */;
       }
       Some(dl) => {
           let sleep = tokio::time::sleep_until(dl);
           tokio::pin!(sleep);
           tokio::select! {
               result = self.config.llm.stream_chat(chat_request) => result?,
               _ = &mut sleep => {
                   return /* Error result with accumulated state, terminal_reason: "timeout" */;
               }
           }
       }
       None => self.config.llm.stream_chat(chat_request).await?,
   };
   ```

5. Add `deadline` parameter to `consume_model_stream` signature (as `Option<tokio::time::Instant>`). Introduce a local enum to disambiguate stream exhaustion from timeout:
   ```
   enum NextEvent {
       Event(LlmEvent),
       Exhausted,
       TimedOut,
   }
   ```
   Replace the bare `stream.next().await` loop with:
   ```
   let next = match deadline {
       Some(dl) => {
           if tokio::time::Instant::now() >= dl {
               NextEvent::TimedOut
           } else {
               let sleep = tokio::time::sleep_until(dl);
               tokio::pin!(sleep);
               tokio::select! {
                   event = stream.next() => match event {
                       Some(e) => NextEvent::Event(e),
                       None => NextEvent::Exhausted,
                   },
                   _ = &mut sleep => NextEvent::TimedOut,
               }
           }
       }
       None => match stream.next().await {
           Some(e) => NextEvent::Event(e),
           None => NextEvent::Exhausted,
       },
   };
   ```
   On `NextEvent::TimedOut`: return `StreamResult` with `outcome: StreamOutcome::TimedOut` and all accumulated `assistant_content`, `reasoning_content`, `pending_calls`, `usage`.
   On `NextEvent::Exhausted`: existing exhausted logic (stream ended without Done).
   On `NextEvent::Event(e)`: existing event processing.

6. Update `run_turn` to: compute deadline, call `self.run_turn_inner(&request, &enabled, None, deadline).await` directly (no wrapper).

7. Update `run_turn_live` to: compute deadline, call `self.run_turn_inner(&request, &enabled, Some(&events), deadline).await` directly (no wrapper).

Critical: `sleep_until(dl)` is preferred over `sleep(remaining)` — it avoids computing remaining and handles already-past deadlines correctly. The pre-check `now >= dl` ensures no race where both select branches are ready and the event branch wins when we should timeout.
