**BlockingLlmClient implementation** (add at top of live_tests.rs, after existing helpers):
- Struct with fields: `pre_block_events: Mutex<Option<Vec<LlmEvent>>>`, `resume: Arc<tokio::sync::Notify>`, `entered_waiting: Arc<tokio::sync::Notify>`, `post_resume_events: Mutex<Option<Vec<LlmEvent>>>`.
- Implement `LlmClient` trait: `chat` returns unreachable, `stream_chat` takes pre_block_events, yields them via `futures::stream::unfold` state machine, then signals `entered_waiting.notify_one()`, then awaits `resume.notified()`, then yields post_resume_events, then ends stream. State machine enum: `Phase::Pre(VecDeque<LlmEvent>, Arc<Notify>, Arc<Notify>, Vec<LlmEvent>)` -> `Phase::Waiting(Arc<Notify>, Arc<Notify>, Vec<LlmEvent>)` -> `Phase::Post(VecDeque<LlmEvent>)` -> `Phase::Done`.
- The `entered_waiting` signal allows the test thread to know the LLM has consumed all pre-events and is now blocked, BEFORE inserting the racing commit. This eliminates timing assumptions.

**Test: `stream_turn_live_commit_failure_deterministic`** (per D-01, D-02, D-03):
1. Create tempdir, `make_session(dir.path())`.
2. Create session via `session.create_session(...)`.
3. First turn: use `FakeStreamingLlmClient` with `happy_events()`, collect stream to completion. Assert `TurnCommitted` present.
4. Build `BlockingLlmClient` with `pre_block_events` = [Token{content:"partial"}, Token{content:" response"}] and `post_resume_events` = [Done{finish_reason:"stop", usage: Some(...)}]. Keep `Arc<Notify>` handle as `resume`.
5. Start second `stream_turn_live` with `make_request_with_session("second turn", &session_id)`. The returned `Ok(stream)` guarantees `prepare_live_turn` completed with stale parent.
6. Wait for `entered_waiting.notified().await` — this guarantees BlockingLlmClient has consumed all pre-events and is now blocked. Only THEN insert racing commit.
7. Insert racing commit: open fresh `make_session(dir.path())`, read `session.log(&session_id)` to get current HEAD commit_id, build `TurnCommitInput` with `parent_ids: vec![current_head]`, commit via `session3.store().commit_turn(racing_input)`.
8. Signal `resume.notify_one()` — BlockingLlmClient resumes, agent finishes, commit_turn_inner finds parent mismatch.
8. Collect stream2 events.

**Test: `stream_turn_live_receiver_drop_does_not_cancel`** (per VER-12):
1. Create tempdir, session, `FakeStreamingLlmClient` with `happy_events()`.

4. Poll session log with timeout instead of fixed sleep — avoids CI flakiness:
   ```
   let committed = tokio::time::timeout(Duration::from_secs(2), async {
       loop {
           let session = make_session(dir.path());
           if session.log(&session_id).map(|log| log.len()).unwrap_or(0) >= 1 {
               break;
           }
           tokio::time::sleep(Duration::from_millis(10)).await;
       }
   }).await;
   assert!(committed.is_ok(), "background task should commit despite receiver drop");
   ```
5. Open fresh `make_session(dir.path())`, read session log. Assert: log has 1 commit (turn completed and committed despite receiver drop).
