# Phase 03 - UI Design Contract

> Visual and interaction contract for the CLI/TUI single-agent UX. Generated by gsd-ui-phase and verified against the six UI contract dimensions.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none |
| Preset | not applicable |
| Component library | ratatui with crossterm backend |
| Icon library | none; terminal text symbols only |
| Font | user terminal monospace font |

Phase 03 is a terminal UI phase, not a web frontend phase. Do not introduce shadcn, Tailwind, React components, custom bitmap assets, web icons, or third-party UI registries. Reuse the existing ratatui widget model, `Theme::catppuccin_mocha`, and current terminal layout conventions.

---

## Spacing Scale

Declared values (must be multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px / 1 terminal column where applicable | Inline gaps between compact status segments |
| sm | 8px / 2 terminal columns | Statusline segment gaps, prompt prefix indentation |
| md | 16px / 4 terminal columns | Shortcut table label lanes and grouped metadata |
| lg | 24px / 6 terminal columns | Wide statusline groups on terminals >= 78 columns |
| xl | 32px / 8 terminal columns | Context bar width and wide command alignment |
| 2xl | 48px / 12 terminal columns | Reserved for wide help tables only |
| 3xl | 64px / 16 terminal columns | Reserved for large welcome banner layout only |

Exceptions: terminal rows are one-cell increments because ratatui layout is row-based. Any horizontal spacing rendered in fixed-width labels must still use 2, 4, 6, 8, 12, or 16 columns. Do not add arbitrary 3, 5, 7, or 10 column alignments.

---

## Typography

Terminal typography is expressed through style modifiers, not font files or viewport scaling.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | terminal cell default | 400 / normal | 1 terminal row |
| Label | terminal cell default | 600 / bold | 1 terminal row |
| Heading | terminal cell default | 600 / bold | 1 terminal row |
| Display | terminal cell default | 600 / bold ASCII banner | 1 terminal row per banner line |

Allowed weights: normal and bold only. Italic may be used only for reasoning/thinking text already represented by `Theme::thinking_style`; do not introduce additional typographic roles. Do not scale text with terminal width.

## Color

Use the existing Catppuccin Mocha-inspired `Theme` values. Keep color functional and restrained so the TUI reads as an operational tool, not a decorative dashboard.

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `bg` `#1E1E2E` | Main terminal background and composer background |
| Secondary (30%) | `surface` `#313244` and `border` `#585B70` | Statusline background, code blocks, dividers, borders |
| Accent (10%) | `highlight` `#CBA6F7`, `assistant_accent` `#89B4FA`, `user_accent` `#B4BEFE`, `tool_accent` `#F9E2AF` | Reserved elements listed below |
| Destructive | `error` `#F38BA8` | Runtime errors, failed commands, denied destructive confirmations |

Accent reserved for: statusline mode pill, slash-command selection highlight, prompt prefix while editing, user/assistant/tool role labels, active search match metadata, focused help keys, and the current agent/profile identity when it replaces plugin status. Accent must not be applied to every command, every status segment, or plain body text.

Semantic colors:

| Token | Value | Usage |
|-------|-------|-------|
| Success | `success` `#A6E3A1` | Ready state, completed turn state, approved permission state |
| Thinking | `thinking` `#9399B2` | Collapsed or expanded reasoning text |
| Subtext | `subtext` `#A6ADC8` | Hints, inactive metadata, secondary rows |

## Interaction Hierarchy

| Surface | Primary Focal Point | Required Contract |
|---------|---------------------|-------------------|
| `lattice run --agent` | Selected profile path/name and streaming turn result | Profile identity appears before turn execution when it differs from default; runtime drift warnings go to stderr and never look like fatal errors when execution continues. |
| TUI welcome | Current agent/profile, model/provider, sandbox mode | Replace plugin count with `agent:<name>` or `agent:<path>` and, when available, a short snapshot hash. |
| TUI statusline | Mode pill, model/provider, status, agent/profile | Replace `plugin:*` / `plugins:*` segment with `agent:<name>` plus `snapshot:<short_hash>` when a session-bound snapshot exists. |
| Composer | Prompt input and queue state | Placeholder remains concise: `Type a message or / for commands`; streaming placeholder remains `Type now to queue the next prompt`. |
| Slash command menu | Available single-agent actions | `/plugins` and `/plugin` must be absent. No compatibility command, no "plugin removed" placeholder. |
| System messages | Snapshot drift, ignored `--agent`, default profile creation | Warnings must distinguish "using session-bound snapshot" from "using current profile file". |
| Tool and approval displays | Tool name, status, arguments/result detail | Existing tool visibility and approval/permission affordances must remain visually recognizable after plugin cleanup. |

Icon-only actions are not used. Every interactive command remains text-addressable through slash commands, key hints, or CLI flags.

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | `Send Message` |
| Empty state heading | `Start a profile-backed session` |
| Empty state body | `Choose an agent profile, then send a prompt. The session keeps using its saved profile snapshot until you start a new session.` |
| Error state | `Could not load agent profile. Check the agent name or path, then run lattice run --agent <name|path> again.` |
| Destructive confirmation | `Create Default Agent`: `No default agent profile exists. Create .lattice/agents/default/agent.toml and continue this run?` |

Additional required copy:

| Scenario | Required Copy Pattern |
|----------|-----------------------|
| Noninteractive missing default | `No default agent profile found at .lattice/agents/default/agent.toml. Create one before running non-interactively.` |
| Interactive default created | `Created .lattice/agents/default/agent.toml. Edit it later to change prompt, tools, model, or security settings.` |
| Session snapshot drift | `Profile changed on disk; continuing with session snapshot <hash>.` |
| Ignored `--agent` on restored session | `Ignoring --agent <name|path>; restored session is locked to snapshot <hash>.` |
| TUI profile label | `agent:<name>` for named/default profiles; `agent:<path>` for explicit profile paths. |
| TUI snapshot label | `snapshot:<hash8>` when an immutable session snapshot is active. |
| Slash command removal | Do not display `/plugins`, `/plugin`, `plugins`, `plugin menu`, or `plugin mode` in help, welcome tips, command suggestions, or statusline text. |

Avoid generic labels such as `Submit`, `OK`, `Cancel`, or `Save`. Use explicit verb-plus-noun labels in prompts and tests.

## Implementation Contracts

### CLI Contract

- `lattice run --agent <name|path> "<prompt>"` is the visible generic agent path.
- Omitted `--agent` renders and behaves as `agent:default`.
- `--model` and `--provider` may be shown as runtime overrides, but copy must not imply they change profile prompt/tools/security semantics.
- `lattice code` is removed; do not preserve it as an alias, hidden preset, menu item, or special copy path.
- CLI user-facing text must not mention pipeline, orchestrator status, plugin loading, plugin execution, or agent-registry validation/listing commands.

### TUI Contract

- The TUI has one active profile/runtime session in Phase 03.
- The statusline order should remain scan-friendly: mode, model/provider, status, token/context, trace, effort, sandbox, agent, snapshot, optional queue/search, fitting hints.
- The welcome screen must show model/provider, sandbox, current agent/profile, and snapshot if available; it must not show plugin count.
- Help rows must preserve existing core workflows: send, newline, help, command menu, new session, clear transcript, find/next match, thinking, expand tool, sandbox/permissions, history/scroll, quit.
- Help rows must remove plugin shortcuts and replace that slot with a single-agent action such as `/status agent`.
- Slash suggestions must contain only active single-agent commands.
- Search, transcript, queue, streaming, thinking, tool details, approvals, permissions, and model/provider display must remain present.

### Snapshot Warning Contract

- Restored sessions continue with the session-bound snapshot.
- Any warning caused by changed profile files is non-blocking when a snapshot is usable.
- TUI warnings are system messages styled with `subtext` or `error` only when execution cannot continue.
- CLI warnings are stderr lines. They must not be printed as JSON fields unless JSON output is explicitly requested by the command path.
