<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| CLI `--agent` input -> profile discovery | User input selects a local file or named profile. |
| Missing default prompt -> filesystem write | CLI may create `.lattice/agents/default/agent.toml` after confirmation. |
| Current profile file -> restored session | Current profile fingerprint is compared with the locked session snapshot. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-03-01 | Spoofing / confusion | `--agent` parsing | mitigate | Treat obvious paths as `ProfileSource::Path`, names as `ProfileSource::Name`, omitted value as `Default`; test each branch. |
| T-03-02 | Tampering | generated temporary run profile | mitigate | Remove generated `"run"` profile from `commands/run.rs`; use loaded profile semantics for prompt/tools/security/context. |
| T-03-03 | Tampering | missing default write | mitigate | Write default only after interactive confirmation; noninteractive mode fails without writing. |
| T-03-04 | Repudiation | restored session profile drift | mitigate | Surface runtime drift warning in stderr/JSON while leaving locked snapshot behavior unchanged. |
</threat_model>
