  TurnStarted { session_id: String, parent_commit_id: Option&lt;String&gt;, branch: Option&lt;String&gt; },
  ModelStarted { provider: Option&lt;String&gt;, model: String },
  ReasoningDelta { content: String },
  TokenDelta { content: String },
  ToolCallStarted { id: String, name: String },
  ToolCallFinished { id: String, name: String, ok: bool, output_len: usize, error_summary: Option&lt;String&gt; },
  ModelFinished { finish_reason: String, usage: Option&lt;TurnUsageSummary&gt; },
  TurnFailed { reason: String },
  TurnCancelled { reason: Option&lt;String&gt; },
  TurnCommitting,
  TurnCommitted { session_id: String, commit_id: String, status: RunTurnStatus },
  CommitFailed { reason: String }
- Add serde attribute: #[serde(tag = "type", rename_all = "snake_case")] (per D-01).
- Keep existing derives: Clone, Debug, Serialize, Deserialize, PartialEq.

In mapping.rs:
- Update map_status: AgentTurnStatus::Failed -> AgentTurnStatus::Error => RunTurnStatus::Error.

In execute.rs — stream_turn_with_deps function:
- Replace the event mapping closure with a new map_agent_event function (or inline match) that maps the 6 new AgentTurnEvent variants 1:1 to TurnEvent equivalents:
  AgentTurnEvent::ModelStarted => TurnEvent::ModelStarted,
  AgentTurnEvent::ReasoningDelta => TurnEvent::ReasoningDelta,
  AgentTurnEvent::TokenDelta => TurnEvent::TokenDelta,
  AgentTurnEvent::ToolCallStarted => TurnEvent::ToolCallStarted,
  AgentTurnEvent::ToolCallFinished => TurnEvent::ToolCallFinished (include error_summary),
  AgentTurnEvent::ModelFinished => TurnEvent::ModelFinished (map usage via TurnUsageSummary::from)
- Before the mapped events, prepend TurnEvent::TurnStarted { session_id: session_id.clone(), parent_commit_id (from transcript), branch: None }.
- After mapped events, derive terminal event from agent_result.status:
  AgentTurnStatus::Error => push TurnEvent::TurnFailed { reason: agent_result.terminal_reason.unwrap_or_default() }
  AgentTurnStatus::Cancelled => push TurnEvent::TurnCancelled { reason: agent_result.terminal_reason.clone() }
  AgentTurnStatus::Completed => no terminal event
- Then push TurnEvent::TurnCommitting.
- Then push TurnEvent::TurnCommitted { session_id, commit_id, status } (replaces old Committed variant).
- Note: CommitFailed is not emitted in the current buffered path (commit errors return Result::Err before reaching event construction). It exists for Phase 16 live path.
